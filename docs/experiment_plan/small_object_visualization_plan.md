# 小目标与细长缺陷可视化计划

## 分析目标

补充 A2MS-DefectNet 对小目标、细长缺陷、边界模糊缺陷和复杂纹理干扰场景的定性与分组评价证据。

## 定量分组建议

- 小目标缺陷：按缺陷区域面积占图像比例划分，阈值需由数据分布统计后确定；
- 细长缺陷：按缺陷外接框长宽比或骨架长度/面积比划分，阈值需人工确认；
- 边界模糊缺陷：优先结合人工标注或边界梯度统计，不得凭主观描述直接定义。
