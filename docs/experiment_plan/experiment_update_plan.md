# 面向《中国图象图形学报》的实验补充计划

本计划不新增任何未经计算的实验数值。所有后续新增指标必须保存脚本、配置、日志、权重路径和输出表格；写入论文前需与 fixed_existing_results.md 或新的结果记录文件一致。

## 1. 必补实验与统计

### 1.1 A2MS-DefectNet-S/B 复杂度统计

- 目标：补齐 Params、FLOPs、模型大小，并与 Base-S、Base-B、BiSeNetV1/V2、DDRNet23slim、STDC1/2、PP-LiteSeg、DMC-Net 等统一比较。
- 建议输入尺寸：NEU-Seg 使用 200 x 200；皮革数据集使用论文训练/测试尺寸，若推理时有 resize/crop，应在表注说明。
- 统计项：Params/M、FLOPs/G、模型权重大小/MB、FPS、测试设备、batch size、是否包含后处理。
- 注意：FLOPs 和 FPS 与输入尺寸、硬件、框架和计时方式强相关，不能直接混用原论文报告值。
- 预期表格：4.5 复杂度与实时性分析表。

### 1.2 类别级 IoU

- 目标：补充 NEU-Seg 三类缺陷和皮革数据集各类缺陷的 class IoU，避免只用 mIoU 掩盖类别差异。
- NEU-Seg 建议类别：夹杂物、补丁、划痕。
- 皮革数据集建议类别：开创伤、刺刮伤、烙印、破洞、皮肤藓、烂面、刺猴。
- 输出：每个模型一行，每个类别一列，同时保留 mIoU。
- 预期表格：4.2 与主流方法对比后的“类别级 IoU 表”。

### 1.3 小目标/细长缺陷分组评价

- 目标：证明 A2MS-DefectNet 对低占比、小目标和细长缺陷确有优势。
- 建议分组定义：
  - 小目标：缺陷掩码面积占图像面积比例低于训练集缺陷面积分布的 25% 分位数，或使用固定阈值并在论文中说明。
  - 细长缺陷：缺陷掩码外接框长宽比高于训练集长宽比分布的 75% 分位数，或使用主轴长度/短轴长度比例。
  - 边界模糊样本：若无人工标记，不建议主观分组；可用边界宽度内预测误差作为分析指标。
- 指标：mIoU、Dice/F1、Boundary F1 或边界 IoU。
- 预期表格：4.4 可视化分析前后新增“小目标/细长缺陷分组评价表”。

### 1.4 小目标/细长缺陷可视化

- 目标：给审稿人直接展示 A2MS-DefectNet 在小目标、细长划痕、边界模糊、复杂纹理干扰下的优势。
- 建议样例：NEU-Seg 至少包含夹杂物、补丁、划痕；皮革数据集至少包含细长刮伤、小面积破损、纹理干扰强样本。
- 对比方法：Base-B、PP-LiteSeg-B、STDC2-Seg、DDRNet23slim、DMC-Net、A2MS-DefectNet-B。
- 图件要求：按模板思路保证图像清晰，建议导出 300 dpi 以上；每个子图标注方法名，缺陷区域可用轮廓或局部放大框辅助说明。
- 预期图表：4.4 可视化分析图。

## 3. 推荐执行顺序

1. 固化现有结果命名：实验表统一使用 Base-S/Base-B 和 A2MS-DefectNet-S/B，保持 v4 稿件一致。
2. 统计本文模型和已有基线的 Params、FLOPs、模型大小。
3. 输出类别级 IoU 表，先覆盖 A2MS-DefectNet-S/B、Base-S/B 和已有主流方法。
4. 实现或复现 DMC-Net，并在 NEU-Seg 上先跑通；若时间允许再补皮革数据集。
5. 从 PIDNet、LETNet、SeaFormer 中选择 1 到 2 个作为近年通用实时网络新增对比。
6. 生成小目标/细长缺陷分组评价表和可视化图。
7. 更新 paper_draft_v4 的相关工作和实验章节，但新增结果必须先写入新的固定结果文件。

## 4. 成本过高时的降级方案

- 最小可接受方案：不新增高成本工业方法复现实验，只新增 DMC-Net 或 PIDNet 二选一，同时补齐 A2MS-DefectNet-S/B 的复杂度、类别级 IoU 和小目标可视化。
- 稳妥写作方案：SPCS-Net、TAG-Net、GCRANet、CDARNet、DASeg-Net、SAID、LGGFormer 只进入相关工作，不在实验表承诺复现。
- 论文表述原则：对未完成复现的方法，正文只讨论其方法思想与任务关系，不写“本文优于该方法”。
