# 2 相关工作

## 2.1 工业表面缺陷分割

工业表面缺陷检测旨在从材料表面图像中定位裂纹、划痕、夹杂、补丁、污渍、破损等异常区域，是钢铁、皮革、芯片、磁瓦和金属零部件质量控制中的关键环节。与图像级分类和边界框检测相比，语义分割能够为每个像素赋予类别标签，更适合描述缺陷的真实形状、面积占比和边界轮廓。因此，对于边缘不规则、尺度差异大、与背景纹理相似或需要后续面积统计的工业表面缺陷，像素级分割比分类和目标检测具有更直接的工程意义。

近年来，面向工业缺陷的分割网络逐渐从通用编码器—解码器结构转向任务特异的轻量化、注意力增强和边界细节建模。DMC-Net 面向实时表面缺陷分割设计了轻量特征提取和多尺度增强模块，并在 NEU-SEG 上报告了速度与精度结果，是与本文任务最接近的近年工业实时分割方法之一（参考文献待核验）。SPCS-Net 通过空间位置注意和跨尺度融合改善多尺度工业缺陷的分割精度，并在 NEU-Seg、MBP-Seg 和 USB-Seg 上进行了验证（参考文献待核验）。TAG-Net 针对钢材表面缺陷语义分割显式估计背景、缺陷和边界注意力图，并利用边界辅助监督提升缺陷边缘定位能力（参考文献待核验）。这些研究表明，工业缺陷分割的关键不只是提高全局语义判别能力，还需要在复杂背景纹理下保留细小缺陷和模糊边界的局部结构。

同时，部分新近工作进一步关注全局上下文、跨域泛化和复杂缺陷形态。GCRANet 利用轻量全局上下文引导机制增强弱缺陷轮廓并抑制背景噪声，面向多个公开缺陷数据集验证像素级缺陷检测的速度—精度权衡（参考文献待核验）。LGGFormer 采用局部引导全局自注意力、跨分支特征交互和边缘引导解码，以兼顾 CNN 的局部细节和 Transformer 的全局建模能力（参考文献待核验）。CDARNet 面向实时金属表面缺陷分割，通过跨维度自适应区域重构抑制背景干扰并增强鲁棒性（参考文献待核验）。TSEDNet 则针对带钢缺陷类别不平衡和信息丢失问题构建任务特异的编码器—多解码器结构（参考文献待核验）。此外，DASeg-Net 将扩散模型与注意力机制引入芯片表面缺陷分割，并通过边缘辅助训练改善弱边缘区域（参考文献待核验）；SAID 将场景提示用于工业缺陷分割，体现了基础模型和提示学习在跨场景缺陷分割中的潜力（参考文献待核验）。不过，这类提示式或扩散式方法的计算成本、训练协议和评估范式与本文实时全监督语义分割网络存在差异，更适合作为相关工作或拓展方向，而不宜直接混入主实验对比。

本文面向工业表面缺陷实时语义分割任务，主实验聚焦 NEU-Seg 和自建皮革缺陷数据集。A2MS-DefectNet 以细节—语义互优化机制为核心，在轻量映射、注意力增强和联合监督约束方面进行任务适配。与上述近年工业缺陷分割方法相比，本文关注的重点是：在保持实时推理能力的同时，提高模型对低占比、小尺度、细长形态和边界模糊缺陷的分割能力。

## 2.2 实时语义分割网络

实时语义分割需要在有限计算资源下完成像素级预测，因此通常围绕轻量骨干、高低分辨率分支、快速上下文聚合和高效特征融合展开。BiSeNetV1 通过空间路径和上下文路径分别保留空间细节与语义上下文，奠定了双分支实时语义分割的一类典型范式（参考文献待核验）。BiSeNetV2 进一步将细节分支和语义分支解耦，并通过引导聚合层融合两类特征，在速度和精度之间取得较好平衡（参考文献待核验）。DDRNet 采用双分辨率结构和多次双向融合，以高分辨率分支保留空间细节，并以低分辨率分支聚合上下文信息（参考文献待核验）。STDCNet 则重新思考 BiSeNet 的结构冗余，通过短期密集连接和细节聚合模块提升实时分割效率，其边缘监督思想也为缺陷边界学习提供了参考（参考文献待核验）。

2022 年以后，实时语义分割进一步向高效注意力、轻量 Transformer 和移动端部署发展。PP-LiteSeg 设计了灵活轻量解码器、统一注意力融合模块和简化金字塔池化模块，以降低解码开销并增强多尺度上下文（参考文献待核验）。PIDNet 受到 PID 控制器启发，将实时语义分割划分为细节、上下文和边界三条分支，并利用边界注意力引导细节与语义融合（参考文献待核验）。LETNet 结合轻量 CNN 与高效 Transformer，用于在通用场景中提升实时语义分割的速度—精度平衡（参考文献待核验）。SeaFormer 及 SeaFormer++ 通过 squeeze-enhanced axial attention 构建移动端友好的语义分割骨干，体现了轻量注意力网络在高分辨率像素预测任务中的发展趋势（参考文献待核验）。

这些通用实时语义分割方法主要在 Cityscapes、CamVid、ADE20K 等自然场景数据集上评估。与自然场景相比，工业表面缺陷图像通常具有缺陷区域占比低、目标形态不规则、类别间纹理相似、背景噪声强和边界模糊等特点。直接迁移通用实时语义分割网络可能难以充分学习缺陷前景和材料纹理之间的细粒度差异。因此，本文将 BiSeNet、DDRNet、STDCNet、PP-LiteSeg、PIDNet 等作为速度—精度对比和结构设计背景，而论文主线始终保持在工业表面缺陷实时分割，A2MS-DefectNet 不转向通用自然场景语义分割叙事。

## 2.3 注意力机制与边界/前景监督约束

注意力机制通过对通道、空间或跨尺度特征进行加权，有助于增强关键缺陷区域并抑制背景纹理干扰。工业缺陷图像中，缺陷区域往往只占图像较小部分，且弱纹理缺陷与正常表面之间差异有限，因而模型容易受到背景纹理、反光、划痕边缘和材料纹理重复模式的干扰。SPCS-Net、TAG-Net、GCRANet、LGGFormer、DASeg-Net 等近年方法分别从空间位置注意、三重注意力、全局上下文引导、局部—全局自注意力和 HiLo 注意力等角度增强缺陷区域响应（参考文献待核验）。这些工作说明，注意力机制在工业缺陷分割中的价值主要体现在多尺度特征选择、弱目标定位、边界强化和背景噪声抑制。

除网络结构外，监督约束对缺陷边界和低占比前景区域同样重要。STDCNet 在实时语义分割中引入细节聚合和边缘监督思想，为在不显著增加推理负担的情况下提升边界学习能力提供了参考（参考文献待核验）。Sub-region UNet 面向弱缺陷分割提出 mask-aware loss，通过前景掩码约束增强缺陷区域与背景区域的区分能力（参考文献待核验）。TAG-Net 和 DASeg-Net 等近年工业缺陷分割方法也将边界或边缘辅助学习用于改善缺陷轮廓定位（参考文献待核验）。这些研究共同表明，针对小目标、细长缺陷和边界模糊缺陷，单纯依赖主分割损失可能不足，需要引入更直接的边界或前景监督信号。

本文在贡献边界上不将边缘细节损失和掩码感知损失本身写成原创损失，而是将二者联合引入 A2MS-DefectNet 的训练过程，构建面向工业表面缺陷实时语义分割的联合监督约束。该约束与细节—语义互优化机制、高效轻量映射模块 ELMM 和自适应注意力模块 AAM 协同作用，目标是在保持实时性的前提下增强模型对多尺度、低占比、细长和边界模糊缺陷的分割能力。
