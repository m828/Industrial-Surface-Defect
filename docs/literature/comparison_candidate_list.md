# 可复现实验候选清单

本清单按“能否合理进入 A2MS-DefectNet 主实验对比”排序。判断原则是：必须是像素级分割；优先选择已在现有结果表中出现、或有官方代码、或与 NEU-Seg/皮革缺陷数据集高度一致的方法；没有官方代码的近年工业方法以相关工作为主，避免制造不可复现实验压力。

## 1. 强烈建议加入实验对比

### DMC-Net

- 适合原因：2025 年轻量实时表面缺陷分割方法，论文明确报告 NEU-SEG 上 mIoU 和 FPS，并给出官方 GitHub 链接，任务与本文“工业表面缺陷实时语义分割”高度一致。
- 与 NEU-Seg/皮革任务一致性：与 NEU-Seg 高度一致；皮革数据集需要重新训练验证跨材料适配。
- 复现难度：中等。需要适配本地 NEU-Seg 和皮革数据集格式、统一训练策略和 FPS 测试环境。
- 是否需要重新训练：需要。不能直接引用原论文结果作为本文结果。
- 预期加入论文哪个表格：4.2 与主流方法对比；4.5 复杂度与实时性分析。

### PIDNet

- 适合原因：CVPR 2023 实时语义分割代表方法，具备细节、上下文和边界三分支，和本文边界监督、细节—语义交互主线相关。
- 与 NEU-Seg/皮革任务一致性：原任务为城市街景，但像素级语义分割任务形式一致；需在 NEU-Seg 和皮革数据集重新训练。
- 复现难度：中等。官方代码可用，但需改数据加载、类别数和小尺寸输入。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：4.2 与主流方法对比；4.5 复杂度与实时性分析。

### PP-LiteSeg

- 适合原因：2022 年实时语义分割强基线，官方 PaddleSeg 可复现，且 fixed_existing_results.md 已有 NEU-Seg 和皮革结果。
- 与 NEU-Seg/皮革任务一致性：本文已有对应工业数据实验结果，适合作为稳定实时基线。
- 复现难度：低到中等。若使用既有结果，可先保留；如补 Params/FLOPs/模型大小，需要重新统计。
- 是否需要重新训练：若沿用已有结果不需要；若统一新协议，需要重新训练。
- 预期加入论文哪个表格：4.2 与主流方法对比；4.5 复杂度与实时性分析。

### STDCNet/STDC-Seg

- 适合原因：CVPR 2021 实时语义分割代表方法，Detail Aggregation/边缘监督思想与本文边缘细节损失来源直接相关；fixed_existing_results.md 已有 STDC1/STDC2 结果。
- 与 NEU-Seg/皮革任务一致性：本文已有对应工业数据结果；适合保留为结构与监督约束相关基线。
- 复现难度：低到中等。已有结果可直接使用；补复杂度需统一统计。
- 是否需要重新训练：若只沿用已有结果不需要；若统一协议则需要。
- 预期加入论文哪个表格：4.2 与主流方法对比；4.3 消融实验来源说明；4.5 复杂度与实时性分析。

### DDRNet

- 适合原因：双分辨率实时语义分割经典基线，fixed_existing_results.md 已有 DDRNet23slim 结果。
- 与 NEU-Seg/皮革任务一致性：已有对应工业数据结果，可作为实时网络对比。
- 复现难度：低到中等。已有结果可先保留；复杂度需补测。
- 是否需要重新训练：若沿用已有结果不需要；若统一协议则需要。
- 预期加入论文哪个表格：4.2 与主流方法对比；4.5 复杂度与实时性分析。

### BiSeNetV1/V2

- 适合原因：实时语义分割经典双分支基线，本文 fixed_existing_results.md 已有 BiSeNetV1-L 和 BiSeNetV2-L 结果。
- 与 NEU-Seg/皮革任务一致性：已有工业数据结果，适合作为传统实时基线。
- 复现难度：低到中等。已有结果可保留；补复杂度需统一统计。
- 是否需要重新训练：若沿用已有结果不需要；若统一协议则需要。
- 预期加入论文哪个表格：4.2 与主流方法对比；4.5 复杂度与实时性分析。

### Sub-region UNet

- 适合原因：弱缺陷分割方法，mask-aware loss 是本文联合监督约束的重要来源之一，fixed_existing_results.md 已有该方法在 NEU-Seg 和皮革数据集的结果。
- 与 NEU-Seg/皮革任务一致性：已有对应结果，和本文前景区域监督关联强。
- 复现难度：低到中等。已有结果可保留；如果审稿要求统一训练协议，需重新训练。
- 是否需要重新训练：优先沿用已有结果；必要时重训。
- 预期加入论文哪个表格：4.2 与主流方法对比；2.3 注意力机制与边界/前景监督约束。

## 2. 可选加入实验对比

### LETNet

- 适合原因：2023 年轻量实时语义分割方法，结合 CNN 与 Transformer，官方代码可检索；可补充近年实时网络对比。
- 与 NEU-Seg/皮革任务一致性：原始任务为通用场景语义分割；任务形式一致但数据分布不同。
- 复现难度：中等。需重写数据加载并调整输入尺寸、类别数、训练轮次。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：4.2 与主流方法对比；4.5 复杂度与实时性分析。

### SeaFormer

- 适合原因：ICLR 2023 移动端语义分割方法，官方仓库可用，代表近年移动端注意力/Transformer 轻量设计。
- 与 NEU-Seg/皮革任务一致性：原始实验为通用语义分割；迁移到工业缺陷需要重训。
- 复现难度：中等偏高。依赖 MMSeg 或仓库配置，需适配小分辨率工业缺陷。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：4.2 与主流方法对比；4.5 复杂度与实时性分析。

### CDARNet

- 适合原因：2025 年实时金属表面缺陷分割方法，任务和 NEU-Seg 高度一致，论文还说明 NEU-Seg 训练/测试划分。
- 与 NEU-Seg/皮革任务一致性：与 NEU-Seg 高度一致；与皮革数据集同属工业表面缺陷，但材质不同。
- 复现难度：高。未检索到官方代码，需要自行实现，复现风险较大。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：若代码可得，进入 4.2 与 4.5；否则仅写 2.1 相关工作。

### TAG-Net

- 适合原因：2025 年基于三重注意力的钢材表面缺陷语义分割方法，在 NEU-Seg 上评估，边界监督与本文相关。
- 与 NEU-Seg/皮革任务一致性：与 NEU-Seg 高度一致；皮革数据集需要重训适配。
- 复现难度：高。未检索到官方代码。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：若代码可得，进入 4.2；否则进入 2.1 和 2.3。

### SPCS-Net

- 适合原因：2025 年工业表面缺陷高精度分割方法，包含 NEU-Seg、MBP-Seg、USB-Seg，多尺度/位置注意力与本文小目标和边界问题相关。
- 与 NEU-Seg/皮革任务一致性：与 NEU-Seg 一致；皮革数据集需额外适配。
- 复现难度：高。未检索到官方代码，且结构包含多个模块。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：若代码可得，进入 4.2；否则进入 2.1 相关工作。

### MLR-Net

- 适合原因：2023 年皮革缺陷分割方法，和本文自建皮革缺陷数据集主题接近。
- 与 NEU-Seg/皮革任务一致性：与皮革缺陷任务一致；与 NEU-Seg 材质不一致。
- 复现难度：中等偏高。未检索到官方代码，需核对原数据集与标签定义。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：若实现成本可控，进入皮革数据集对比表；否则进入 2.1。

## 3. 只写相关工作，不复现实验

### GCRANet

- 不复现实验原因：2026 年 Pattern Recognition 方法质量高，任务为像素级表面缺陷检测/分割且强调轻量实时，但未检索到官方代码，数据集与本文 NEU-Seg/皮革并不完全一致。
- 与 NEU-Seg/皮革任务一致性：SD-saliency-900 与 NEU-Seg 任务接近；皮革不一致。
- 复现难度：高。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：2.1 相关工作；可在 4.2 后的补充讨论中说明“若代码公开可作为后续对比”。

### LGGFormer

- 不复现实验原因：方法侧重 CNN/Transformer 双分支和边缘引导，适合写相关工作；未核到官方代码，完整复现成本较高。
- 与 NEU-Seg/皮革任务一致性：同属表面缺陷分割，但需核验具体数据集和协议。
- 复现难度：高。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：2.1 和 2.3 相关工作。

### DASeg-Net

- 不复现实验原因：扩散模型分割与注意力机制有参考价值，但模型复杂度和训练成本较高，且主任务为芯片表面缺陷，与本文实时轻量主线不完全一致。
- 与 NEU-Seg/皮革任务一致性：同属工业缺陷像素级分割，但材料和图像分布不同。
- 复现难度：高。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：2.1 和 2.3 相关工作，不进入主实验。

### SAID

- 不复现实验原因：提示式工业缺陷分割强调单标注/跨场景适配，与本文全监督实时语义分割网络评估协议不同。
- 与 NEU-Seg/皮革任务一致性：都是工业缺陷分割，但 SAID 的提示式评估协议不宜和 A2MS-DefectNet 直接横向比较。
- 复现难度：高。
- 是否需要重新训练：可能需要按其提示学习协议训练/适配，不适合本文主表。
- 预期加入论文哪个表格：2.1 背景或讨论段。

### TSEDNet

- 不复现实验原因：面向长尾带钢缺陷和任务特异解码，适合说明工业缺陷类别不平衡问题；未检索到官方代码。
- 与 NEU-Seg/皮革任务一致性：与带钢缺陷相关；与皮革不一致。
- 复现难度：高。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：2.1 相关工作。

### DDSNet

- 不复现实验原因：需要进一步核验 IEEE TIM 正式论文页、数据集和代码情况；当前仅可作为近年双分支缺陷语义分割补充。
- 与 NEU-Seg/皮革任务一致性：同属表面缺陷语义分割，具体协议待核验。
- 复现难度：高。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：2.1 相关工作。

### SeaFormer++

- 不复现实验原因：IJCV 2025 扩展版更适合作为移动视觉骨干背景；若已复现 SeaFormer，则无需同时在主实验复现 SeaFormer++。
- 与 NEU-Seg/皮革任务一致性：原始任务为通用移动语义分割，不是工业缺陷。
- 复现难度：中等。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：2.2 实时语义分割网络。

### Residual Shape Adaptive Dense-nested UNet

- 不复现实验原因：2024 年 Pattern Recognition 小目标/形状自适应缺陷像素级检查方法，适合作为小目标缺陷背景；未检索到官方代码。
- 与 NEU-Seg/皮革任务一致性：同属金属表面微小缺陷像素级定位；不完全覆盖皮革。
- 复现难度：高。
- 是否需要重新训练：需要。
- 预期加入论文哪个表格：2.3 注意力机制与边界/前景监督约束，或小目标分析背景。

## 推荐最小实验增补组合

若时间有限，建议优先补：

1. DMC-Net：近年工业缺陷实时分割，官方代码可核验，和 NEU-Seg 最匹配。
2. PIDNet：CVPR 2023，边界分支与本文边界监督相关。
3. LETNet 或 SeaFormer 二选一：补充 2023 后轻量 Transformer/CNN 实时网络。
4. 保留现有 PP-LiteSeg、STDCNet、DDRNet、BiSeNetV1/V2、Sub-region UNet 结果，并补 Params/FLOPs/模型大小。

若实验成本过高，DMC-Net 仍建议优先尝试；TAG-Net、SPCS-Net、CDARNet、GCRANet 可先写相关工作，不承诺主实验复现。
