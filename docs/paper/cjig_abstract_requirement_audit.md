# CJIG 摘要要求核验 (cjig_abstract_requirement_audit)

> 日期：2026-09-28
> 来源：[中国图象图形学报 撰稿要求（官网 cjig.cn）](https://www.cjig.cn/zh/info/13448/)

## 核验结果

| 项目 | 官网要求 | v5 现状 | 判定 |
|---|---|---|---|
| 中文摘要结构 | 按"目的/方法/结果/结论"小标题逐项撰写 | 已按四段式 | ✓ |
| 英文摘要结构 | 按"Objective/Method/Result/Conclusion"小标题逐项撰写 | 已按四段式 | ✓ |
| 摘要字数 | **500 字左右**，中英文摘要**无需对应** | 中文约 620 字；英文约 380 词 | 中文略超，英文接近，均在"左右"容差内 |
| 关键词 | 中英文关键词 | 中文 6 个、英文 6 个对应 | ✓ |
| 引言节序号 | 从 0 开始 | 0 引言 | ✓ |
| 图名表名 | 中英文对照 | 全部图表标题中英对照 | ✓ |
| 图件 | 自明性、300dpi 以上 | PNG 600dpi + PDF + SVG | ✓ |

## 结论

- 网传"英文摘要需 1000 词"并非 CJIG 官方当前要求（官方为 500 字左右、中英无需对应）；v5 英文摘要按 ~380–450 词控制即可，不再扩充。
- 中文摘要可微压缩，但不构成投稿阻塞。

## 附：其他格式要点（供排版阶段）

- 首页脚注：基金项目标准名称（中英文）及编号；第一作者简介（出生年、职称/职务、学历、研究方向、E-mail）；学生一作建议提供通信作者信息。
- 页眉：中图法分类号。
- 标题层次不超过 3 级。
