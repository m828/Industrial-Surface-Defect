# 论文实验结果更新协议

## 基本流程

1. 新实验完成后，先记录到 `experiments/results/new_results_pending.md`；
2. 核对训练日志、测试日志、权重路径、测试脚本和输出表格；
3. 确认输入尺寸、训练策略、测试设备、FPS 计时方式和是否包含后处理；
4. 将核验后的结果同步到 `experiments/results/fixed_existing_results.md`；
5. 再更新论文实验表、摘要、结论或图件说明。

## 新增结果必须注明

- 数据集；
- 输入尺寸；
- 训练策略；
- 测试设备；
- FPS 计时方式；
- 是否包含后处理；
- 训练脚本；
- 测试脚本；
- 权重路径；
- 结果输出路径。

## 禁止事项

- 不得将未核验结果直接写入摘要、结论或主实验表；
- 不得用口头描述替代表格记录；
- 不得把缺失的 Params、FLOPs、模型大小自动补全；
- 不得把未复现的文献方法写入主实验对比表；
- 不得在正文主线中恢复旧最终模型名。
