## 5. 评价实现与效率口径

补充评价包含背景，采用相同测试列表与指标计算。源审计说明：DeepLabv3+ / FDSNet 使用项目评价工具；U-Net 为避免 NEU 尺寸封装错误地裁剪 768×768 输入，采用原生 768 构建的扩展评价驱动。扩展驱动在 DeepLabv3+ / FDSNet 上与项目工具交叉核查，mIoU 差小于 5×10⁻⁷。

不将这种交叉核查写成“三个模型都直接使用原作者官方工具”，也不声称已通过另一条独立执行链重测 U-Net。

新扩展的 768×768、均值延迟测速与正文 NEU 的 200×200、中位延迟单图等效 FPS 口径不同。本轮不引入新增 Leather 效率数字；正文既有十模型前向计时仅作表号顺延，数值和共享 GPU 限定不变。
