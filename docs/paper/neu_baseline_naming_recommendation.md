# NEU 基线命名建议 (neu_baseline_naming_recommendation)

> 日期：2026-09-28
> 依据：`experiments/audit/neu_dsmonet_base_identity.md`（IDENTITY-A：当前 Base-B 与大论文 DSMONet-B 计算图同一）

## 结论：推荐方案 B —— 首次定义后简称

推荐写法（方法/实验节首次出现处）：

> 本文以团队前期提出的 DSMONet（ResNet-50 主干，以下简称 Base-B）为基础网络……

此后全文统一用 **Base-B**。

## 理由

1. IDENTITY-A 已实证：不声明渊源会把已有工作包装成新 baseline（学术风险）；
2. 纯用 DSMONet-B（方案 A）会让消融表（Base-B / +AAM / +细节监督）的阅读负担增加，且 "Base-B" 已在全部审计链与表格中使用；
3. 方案 B 同时满足"承认历史连续"与"行文简洁"。

## 数字处理建议

- 正文只使用当前统一协议结果：**91.24%（Base-B，240k 固定终点，840 张）**；
- 大论文 90.2% **不进入正文**，不与 91.24 并列展示；
- 禁止表述："DSMONet-B 从 90.2 提升到 91.24"；
- 如需提及历史，可在相关工作/披露中写"前期工作中该基础网络已验证有效"，不引具体数字。
