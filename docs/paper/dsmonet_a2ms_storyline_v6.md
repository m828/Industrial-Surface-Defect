# DSMONet → A2MS-DSMONet 论文主线说明 (dsmonet_a2ms_storyline_v6)

> 日期：2026-09-28
> 用途：记录 v6 技术主线的完整逻辑链，供后续修改保持一致性，也供回复审稿人时引用。

## 一、主线逻辑链

```
实时语义分割的通用矛盾：
  高层语义判别能力  vs  局部空间结构保持
        ↓
DSMONet（第一层）
  细节—语义相互优化基础架构
  深层语义 → 约束浅层细节（抑制背景纹理响应）
  优化细节 → 反向补偿深层语义（位置/结构信息）
  结构设计不依赖特定缺陷类别
        ↓
工业表面缺陷的任务特性：
  低占比 / 弱纹理 / 多尺度 / 类间形态差异大 / 边界模糊
        ↓
A2MS-DSMONet（第二层 = DSMONet + 工业适配增强）
  ① AAM（eSE + ACW）：嵌入互优化路径的自适应通道重标定
  ② 辅助细节监督：仅训练阶段约束局部结构学习
        ↓
双数据集验证
  NEU-Seg（公开带钢，固定终点协议）：91.24 → 91.45（+0.21 pt），37.37 FPS
  Leather（真实皮革，验证集选择协议）：89.91 → 90.97（+1.06 pt）
        ↓
细粒度形态分析
  斑块：区域+边界同步改善（收益最明确）
  裂纹：区域完整性 ↑ 但边界定位权衡（形态越复杂折中越明显）
  夹杂物：稳定
  皮革：6/7 类正向，刺猴 −3.75 pt
        ↓
结论：总体正向 + 增强效果形态依赖（不做"所有类别统一提升"声称）
```

## 二、两个模型名的正式定义（全文唯一）

- **DSMONet-B**：细节—语义相互优化网络，ResNet-50 主干。代码：`new/model_dsmo_rs50.py`（与 2023 年历史版 `subregion unet/model_dsmo_rs50.py` 计算图同一，IDENTITY-A）。
- **A2MS-DSMONet-B**：在 DSMONet-B 上引入 AAM + 辅助细节监督的完整模型。代码：`new/model_dsmo_rs50_eSE_adapt_detailloss_fixed.py`（head_seg1=out）。
- `-B` 后缀含义：ResNet-50 主干（backbone），在 1.1 节首次出现时说明。
- 废弃名：Base-B（2026-05 实验整理期人工简称，v6 起不再出现于正文；audit 档案保留）。

## 三、91.24 与 90.2 的关系（防混淆）

- 大论文历史值：DSMONet-B = 90.2%（历史 test-monitor 峰值口径，832/840，约 52k–60k 训练阶段）。
- 当前论文值：DSMONet-B = 91.24%（240k 固定终点、统一 840、无测试集模型选择、seed1337、from scratch）。
- 二者是**同一架构在不同训练预算与评价口径下的两个结果**，不是模型改进。
- 正文只使用 91.24%；90.2% 不进入正文；禁止"从 90.2 提升到 91.24"表述。
- 完整证据链：`experiments/audit/neu_90_2_vs_91_24_diff.md`、`neu_dsmonet_base_identity.md`。

## 四、创新层级（防止堆砌式创新声称）

- Layer 1（架构）：细节—语义互优化 —— DSMONet。
- Layer 2（任务适配）：AAM + 辅助细节监督 —— A2MS-DSMONet。
- Evidence（证据层）：双数据集 + 多维度形态分析。
- 明确非创新点：mask-aware loss（引自 Zhu 等 2023）、detail supervision 思想（STDC 系列）、OHEM。

## 五、标题候选（当前保留主标题，备选待用户决定）

- 主标题（现用）：**语义—细节协同增强的工业表面缺陷实时语义分割网络** —— 覆盖面宽，同时容纳两层结构。
- 备选 1（强调互优化+工业增强）：**细节—语义互优化的工业表面缺陷实时分割网络及其自适应增强**。
