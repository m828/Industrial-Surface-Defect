# Figures

本目录用于存放论文图件占位与后续重绘结果。不要提交来源不明、版权不清晰或期刊政策不允许复用的图片。

## 子目录

- `architecture/`：A2MS-DefectNet 总体结构图；
- `modules/`：ELMM、AAM、联合监督约束等模块图；
- `dataset_samples/`：NEU-Seg 和皮革缺陷数据集样例图；
- `qualitative_results/`：小目标、细长缺陷、边界模糊和纹理干扰场景的可视化结果。

## 图件要求

- 投稿图建议使用矢量图或 300 dpi 以上位图；
- 图题、表题需中英文对照；
- 未确认图件标记为 TODO_FIGURE；
- 不提交原始数据集图片和标签，必要时只提交经许可的论文展示样例或低风险示意图。
