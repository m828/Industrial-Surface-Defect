## 一、论文实验结构需求

一篇完整的工业表面缺陷分割论文通常需要以下实验板块：

| 板块 | 内容 | 优先级 |
|---|---|---|
| A. 主实验对比表 | 多方法在 NEU-Seg + Leather 上的 mIoU、FPS、Params | P0 |
| B. 类别级 IoU | 各方法在各数据集上的 per-class IoU | P0 |
| C. 复杂度对比 | Params、FLOPs、FPS、模型大小 | P0 |
| D. 消融实验 | 提出方法的各模块贡献 | P0 |
| E. 可视化分析 | 定性对比图、典型场景展示 | P1 |
| F. 小目标分析 | 不同缺陷尺度/形态的性能分析 | P1 |
| G. 统计显著性 | 多次运行标准差、p-value | P2 |

## 四、关键决策点（需人工确认）

1. **历史结果是否可直接使用？**
   - 硕士论文的实验在 RTX 3090 + PyTorch 1.10 上完成
   - 当前服务器为 A100 + PyTorch 2.7
   - FPS 数据因硬件不同不可直接比较，但 mIoU 应一致
   - **建议**：mIoU 可沿用历史结果（标注"历史结果"），FPS 需在当前硬件上重新测量

2. **主实验表需要多少个对比方法？**
   - 历史结果表有 23 个方法（NEU-Seg）/ 14 个方法（Leather）
   - 中文期刊论文通常 8-12 个对比方法即可
   - **建议**：精选 10-12 个有代表性的方法，不必全部复现

3. **哪些方法可以精简？**
   - 代码缺失且无法复现的方法（BiSeNetV2, PP-LiteSeg-T）→ 引用论文结果
   - 非主流方法（FDSNet, PGA-Net）→ 可选保留
   - 经典方法（FCN, U-Net, DeepLabV3+）→ 作为大模型代表保留

4. **PIDNet-S 是否需要在 Leather 上训练？**
   - 当前仅在 NEU-Seg 上有完整结果
   - 如果 PIDNet-S 作为重点对比方法，建议在 Leather 上也训练

5. **消融实验是否需要重新运行？**
   - 历史消融数据可直接使用
   - 如果审稿人要求，可在当前服务器上复现
