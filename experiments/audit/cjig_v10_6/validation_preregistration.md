## 1. RQ1：统计口径与区域—边界方向是否可重复

### 1.1 预定输出（全部必报，不得选择性省略）

1. `class_id1` GT 阳性共同集的区域 IoU 配对差（A2−Base）。
2. 同一病例集合的对称形态学边界带 IoU@2 配对差。
3. 两指标共同有效集合上的同向/异向/并列计数（并列阈值 |Δ|≤1e-6）。
4. 全 840 像素聚合 IoU 差（ΣTP/Σunion）。
5. GT 阳性同一集合上的聚合 IoU 差。
6. 等权逐病例 IoU 均差。
7. union 权重数学分解：固定 Base union 权重的质量项 + union 重加权项（要求两项之和与聚合差闭合到 1e-12）；union=0 的病例只进入逐病例集合、不进入聚合权重分解的除法路径，按 v10.4 已核验实现处理。
8. Estimand A（各自有效集合均值差）/B（共同有效集合配对均差）/C（GT 阳性共同集合配对均差）及各自 n 与样本 ID 集合。
9. GT 阴性图像的误报：class_id1 GT=0 且预测>0 的像素数与病例清单（含 000510/000529/000597/000524/000526 等已知病例在新权重下的对应表现）。
10. 全部预定类别（class_id1/2/3）与全部预定边界容差（BIoU@1/2/3、BF1@1/2/3）结果。

### 1.2 冻结规则

- 空例规则：GT 空+预测空→NA；单方空→0；边界带/contour 双空（含全图 mask）→NA；与 v10.4 合成测试一致。
- Bootstrap：5000 次、seed20261018、**按图像**重抽样、两模型共用抽样索引、百分位 95% 区间、不修改空例规则、记录空重复次数；多 seed 时**跨 seed 复用同一批抽样索引**以便比较。区间解释为固定权重下测试病例抽样不确定性，不得称为跨种子稳定性区间。
- 主要判读对象：`class_id1` 的 1、2 两项配对差及其符号；其余为必报的支撑项。
- 不得为接近 1337 结果而调整指标、容差、集合、空例规则或权重选择。

## 2. RQ2：高复杂度条件差异能否重复

### 2.1 冻结定义

- 仅针对 `class_id1`。
- 复杂度 = 一次腐蚀内轮廓像素数 / sqrt(GT 面积)（与 v10.4 复算一致，**非几何周长**）。
- 分组：沿用 1337 GT 已冻结的三分位样本集合（low n=121 / mid n=122 / high n=121；1337 观测范围 low 5.5026–9.7524、mid 9.7564–11.9290、high 11.9667–19.2827，仅作记录，不重新估计阈值）。面积粗分同样沿用冻结 P33/P67（class_id1：0.027324 / 0.06185775；class_id2：0.1064235 / 0.18496475；class_id3：0.037379 / 0.08505）。
- 分组 ID 的权威载体：`cjig_v10_4/audit_reports/recomputed_case_metrics.csv` 与 `rq2_complexity_reproduction.csv` / `rq2_area_reproduction.csv`。

### 2.2 预定输出

1. 高复杂度组 Base 绝对 IoU 与 A2MS 绝对 IoU（**必须先报绝对值再报差值**）。
2. 高组配对差、低组配对差。
3. **H = 高组配对差 − 低组配对差**（相对退化量）。
4. 高×粗面积三档交叉的配对差与 n。
5. 连通组件数量与复杂度/面积的关联（**仅探索性**，不得写作预注册验证）。

### 2.3 判读纪律

- 高组差值为负但低组更负（H>0）时，**不得宣称高复杂度更易退化**；必须同时报告 H、两组配对差与两组绝对 IoU。
- 不得通过改分组、改容差、加 seed 追求 H<0。
