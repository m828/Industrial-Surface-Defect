# 剩余来源证据缺口与 NOT RUN 清单

## 1. 原始采集与制作谱系

仍缺以下原件或作者记录：

- 原始相机/采集批次 ID，以及每个派生文件到原图的映射；
- 原始 LabelMe JSON 或其他标注导出文件、标注版本说明；
- 旋转、重编码、翻转等离线增强脚本及运行日志；
- `training/test` 清单和目录的生成脚本、随机种子、复制/重命名记录；
- 当前服务器最初下载 NEU-Seg 的操作记录；
- 能证明“先增强后划分”或其他形成顺序的直接材料。

本轮固定上游树及公开 issue 检查没有补上这些缺口。`external_provenance_leads.json` 保留后续论文与作者代码库线索，但二手描述不等于原始谱系证明。

## 2. 类别语义与授权

- 上游固定树没有整数 ID 到缺陷名称的映射；本轮没有取得新的语义认证。任何 `class_id1=scratches` 或其他名称都不能凭外观或第三方命名直接指定。
- 后续 AFFNet 论文将 NEU-Seg 的 LabelMe 制作归于 Bao 等人，可作为索取原始材料的线索；Bao 论文全文中的数据制备细节未能在本环境取得，不能声称已审核。
- 上游仓库 API license 字段为 null，固定树没有 LICENSE；GT 再分发授权没有新增证据。
- 公开证据包不包含原始图像、GT、LabelMe、checkpoint、上游数据归档或数据集访问密码。

## 3. 历史运行与增强张量

- 训练前 manifest 有清单 SHA，但没有训练当时的 8940 文件逐文件快照。当前源文件、运行路径、日志、mtime 和固定上游匹配构成强证据链，但不能把 mtime 当作独立密码学证明。
- 在线增强参数没有逐样本/逐 epoch 保存，实际历史增强张量未恢复。
- 本轮没有重放 DataLoader 来推断增强序列，因为该操作不能证明原始采集身份，也不是任务要求的新实验。

## 4. 来源家族证据等级

- `DIGITAL_IDENTITY_VERIFIED` 和 `TRANSFORM_EQUIVALENCE_VERIFIED` 是数字/像素级事实，不等于作者确认的相机采集家族。
- `HIGH_CONFIDENCE_SHARED_SOURCE_CANDIDATE` 是回顾性阈值下的候选，不能写成已证实泄漏数量。
- GT-only D4 或相似掩码不能单独合并图像来源家族。
- 当前没有作者确认的采集证明家族；`acquisition_proven.components_total_including_singletons=null` 是有意保留的不可知状态，不是“真实家族数为零”。

## 5. 尚未执行的任务（全部 NOT RUN）

- 模型训练、模型前向推理、checkpoint 加载或重新选权；
- 新 mIoU 或其他模型预测指标评价；
- 原 840 记录或来源簇的新 Bootstrap；
- 删除测试样本后的“独立”评价；
- 新 train/test/validation 划分或数据重标注；
- 新多种子 240k 训练或机制消融；
- 论文正文修改；
- 原始图像、GT、checkpoint、敏感数据或凭据上传。

## 6. 作者下一步可提供的决定性材料

1. NEU-Seg 原作者的采集/增强/划分说明和整数类别映射；
2. 原始 LabelMe/标注导出与版本历史；
3. 派生图像到采集 ID 的表，或一个独立、未参与任何训练/调参的外部测试集；
4. 明确的数据使用及再分发许可。

在这些材料到位前，稿件只宜进行限定内部结果审查，不应升级为独立泛化或已证实普遍机制结论。
