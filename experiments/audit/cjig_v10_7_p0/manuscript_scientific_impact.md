# P0-6 对当前论文证据与后续独立评价的影响

## 总体判断

**MANUSCRIPT SCIENTIFIC READINESS = HOLD FOR SOURCE EVIDENCE。**

本轮没有修改任何冻结结果。DSMONet-B 0.9124083744680408 与 A2MS-DSMONet-B 0.9145442177671137 仍是同一批 840 条评价记录上的可复算算术结果，但至少一对跨 split 图像精确 D4 等价已被确认，原始采集谱系又未闭合，因此不能把这些记录直接解释为 840 个独立采集对象上的泛化证据。

## 逐项影响

### 1. 能否继续报告 91.24% 和 91.45%

可以保留为**固定上游版本、固定 train/test 清单、固定权重和既定评价协议下的内部结果**，并明确包含背景、200×200、主输出及记录级 mIoU 定义。不得改数。

若继续写作，需要同步限定：测试记录存在数字重复和跨 split 图像变换等价，结果不构成独立采集图像上的无泄漏泛化证明。若稿件用“独立测试集”“独立 840 图像”支持广泛泛化或临床/工业部署效果，相关表述应暂停，等待作者科学审查。本轮不修改论文。

### 2. 840 条记录是否是 840 个独立采集图像

**不能。** `test:000301/000305` 是同一数字图像的两个 GT 版本；`test:000717` 与 `train:004097` 存在精确 r180 图像等价。更多近重复只能按候选等级统计，不能一并写成已证实采集重复，但也不能反向假定采集独立。

### 3. 原 840 记录 Bootstrap 的准确含义

原区间只能描述：**在两个固定模型权重和当前固定清单条件下，对 840 条测试记录按记录重抽样的病例抽样不确定性。** 它不是独立采集簇区间、不是跨随机种子稳定性区间，也没有消除同源记录被共同重抽或过度代表的问题。当前没有执行新的 cluster Bootstrap。

### 4. RQ1 哪些仍是固定数据上的数学事实

像素聚合与逐病例平均的差异、union 重加权分解、区域与边界指标同向/异向计数，仍可由原始预测和 GT 复算，属于固定 mask 上的描述性数学事实。

这些事实不自动升级为模块因果机制，也不支持“普遍的区域—边界权衡”。跨 split 同源或测试内重复可能改变某些记录及其 union 权重对聚合结果的贡献，需做来源簇敏感性分析后才能判断稳健性。

### 5. RQ2 哪些受来源独立性风险影响

面积、复杂度及连通性分组本身仍可从 GT 重现，但同组可能包含旋转版本、重复标注或近重复图像，组内有效样本数不再等于独立采集数。高复杂度裂纹的形状复用尤其需要检查 GT D4 组与图像来源图之间的关系。未经分层敏感性复算，不应把组间差异直接推广到独立缺陷病例总体。

### 6. 是否需要来源簇 Bootstrap 敏感性分析

需要，但应分别报告而不能混为一种“真值”：

1. 数字身份/精确图像 D4 簇；
2. 全复核高置信同源候选簇；
3. 若有作者补充采集 ID 后的采集证明簇。

前两类是基于不同证据规则的敏感性情景，不是已证实采集家族。GT-only 相似不能单独定义图像来源簇。本轮 **NOT RUN** 任何新 Bootstrap。

### 7. 是否需要新的独立划分

若目标是独立泛化主张，**需要采集家族级的新划分或真正独立的外部评价数据**。仅把几条测试记录删除，不能证明消除对应训练曝光风险，也不能自动恢复独立性。由于原始采集 ID 缺失，当前候选图最多支持风险敏感性划分，不能保证创建出真正采集独立的划分。

### 8. 既有模型能否做只读敏感性评价

技术上可以仅使用已保存预测，按数字身份、精确 D4 和候选来源簇分层复算，无需重新推理。但这是**固定权重在既有数据上的敏感性分析**，不是新的独立测试；删除测试子集也不能证明已消除训练曝光风险。任何此类分析都需另行冻结规则，本轮 **NOT RUN**。

### 9. 什么时候才值得运行新的多种子训练

先明确研究问题并建立可辩护的来源簇/独立评价协议，再决定训练。当前split上增加随机种子只能估计训练随机性，不能修复同源曝光或证明独立泛化。若进行新的训练，需先冻结家族级划分、固定终点、预测缓存和来源审计规则，不能根据结果挑选划分或 checkpoint。

### 10. 新训练是否必须先重建采集家族级划分

若新训练用于“独立泛化”结论，必须先重建或取得独立外部评价；若仅用于固定清单上的训练方差分析，可沿用旧清单但必须明确其非独立限制。当前最优先不是直接重训，而是补齐原始采集/增强/划分证据并评估候选簇对既有结论的敏感性。

## 当前是否有足够证据决定重新训练

- **足以决定：**暂停把“当前 split 上增加多种子训练”当作解决数据独立性的方案，也不以此追求更强泛化表述。
- **尚不足以决定：**一个已被证明采集独立的新划分、预期修正后的 mIoU、或哪几个样本删除即可解决问题。原始采集 ID 和形成顺序仍缺失。
- 是否基于候选情景开展新训练，应由作者在审阅本证据包后决定；本轮 **NOT RUN** 训练、推理、重标注、重划、checkpoint 选择或新统计评价。

## 交付边界

本报告是数据谱系与统计解释审计，不是模块消融。最终候选覆盖和家族统计以 `cap_resolution/` 的合并结果及独立复核为准；原始 LSH 近重复汇总存在实现缺陷，不用于论文。
