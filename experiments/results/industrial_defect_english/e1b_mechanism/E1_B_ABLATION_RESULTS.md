## 8. 重点科学解释

### seed2027 的反向结果

既有 E1-A 中 coupled−formal 为 −0.000559，coupled−capacity 为 −0.003675；1337和3407对应比较均为正。E1-B 进一步显示，2027 的 stage1−head_shift 为 −0.005023，而 coupled−stage1 为 +0.003409。该 seed 的简化路径排序与其他 seed 不同，完整 coupled 也未超过 formal/capacity。结果不支持删除或选择性忽略2027。

### class 1 改善来源

- 第一阶段主融合：stage1−head_shift 的 class 1 平均 +0.057275。
- 最终语义回流：coupled−stage1 的 class 1 平均 +0.009524。
- 辅助细节输入修正：coupled−no_head_shift 的 class 1 平均 +0.020436，且高复杂组 +0.015060。

在本地开发协议下，class 1 收益同时关联第一阶段主融合和辅助细节修正，而非仅由最终回流产生。由于 stage1/head_shift 的 seed 方差较大，不能把均值拆分成普适的因果贡献比例。

### class 3 退化与权衡

coupled 的 class 3 均值低于 formal；coupled−no_head_shift 的 class 3 为 −0.001529，并伴随 class 3 FN 平均增加7481.7像素。辅助细节修正对 class 1 有利，但对 class 3 可能存在权衡。现有结果可指出关联和错误构成，不能证明具体神经计算因果。

### 是否支持完整跨阶段共享 T

提供**有限支持**：完整 coupled 的平均 mIoU/前景mIoU 为所有条件最高，对 no_head_shift 三 seed 全胜，对 stage1 两个 seed 为正。最终回流在3407为负，因此不支持“完整机制在所有 seed 或所有类别上均更优”的强主张，也不称统计显著。

## 9. 下一步建议

优先保留完整 coupled 作为候选，并针对 class 2/3 FN、class 3 权衡及 seed 稳定性开展后续科学审查或针对性优化；不建议仅追求总体 mIoU。跨数据集验证可用于检验泛化，但不能替代上述稳定性与类别权衡分析。本轮未启动任何新优化或跨数据集实验。
