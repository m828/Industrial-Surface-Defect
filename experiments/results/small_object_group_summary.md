## 分组规则

| 组别 | 定义 |
|---|---|
| 小目标 | 缺陷面积占图像面积 < P25（仅含缺陷样本） |
| 中等目标 | P25 ≤ 面积占比 < P75 |
| 大目标 | 面积占比 ≥ P75 |
| 细长缺陷 | 外接框长宽比 > P75 且有缺陷 |
| 多缺陷 | 连通域数 > 1 |
| 无缺陷 | 缺陷面积 = 0 |

注：标签为语义掩码（非实例级），连通域数量基于二值缺陷掩码的连通域分析近似统计。

### 分析要点

- 小目标缺陷：面积占比最低的 25% 缺陷样本，检验模型对微小缺陷的检出能力。
- 细长缺陷：长宽比最高的 25% 缺陷样本，检验模型对条状/线状缺陷的分割连续性。
- 多缺陷：同一图像包含多个缺陷连通域，检验模型对多实例的区分能力。
