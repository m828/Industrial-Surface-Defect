# 小目标/细长缺陷分组评价计划

## 目标

对 NEU-Seg 和皮革数据集中的小目标缺陷和细长缺陷进行分组统计，评估模型在不同缺陷尺度和形态上的性能差异。

## 前置条件

- [ ] 完成类别级 IoU 评估（`evaluate_class_iou_plan.md`）
- [ ] 定义分组规则（面积占比、长宽比）
- [ ] 统计各分组的样本数量
- [ ] 确认标注格式以提取缺陷区域几何信息

## 分组规则（待人工确认）

### 按面积占比分组

| 分组 | 面积占比范围 | 说明 |
|---|---|---|
| 小目标 (small) | < 1% | 缺陷区域占图像面积 < 1% |
| 中等目标 (medium) | 1% ~ 5% | 缺陷区域占图像面积 1%~5% |
| 大目标 (large) | > 5% | 缺陷区域占图像面积 > 5% |

### 按长宽比分组

| 分组 | 长宽比范围 | 说明 |
|---|---|---|
| 细长 (elongated) | > 5:1 | 缺陷最小外接矩形长宽比 > 5 |
| 中等 (moderate) | 2:1 ~ 5:1 | 长宽比 2~5 |
| 均匀 (compact) | < 2:1 | 长宽比 < 2 |

### 按边界模糊程度分组（可选）

| 分组 | 说明 |
|---|---|
| 清晰边界 | 缺陷与背景对比明显 |
| 模糊边界 | 缺陷边缘与背景纹理交织 |

## 评估指标

每个分组计算：
- **mIoU**：该分组内所有样本的平均 IoU
- **Dice**：该分组内所有样本的平均 Dice
- **Boundary F1**：边界 F1 分数（需确认实现）
- **Recall**：该分组的平均召回率

## 输出格式

### CSV 格式

```
model,dataset,group_type,group_rule,num_samples,miou,dice,boundary_f1,recall,script,weight_path,date,verified
```

## 实现步骤

1. 从标注图像中提取各类缺陷区域的连通域
2. 计算每个连通域的面积占比和长宽比
3. 按规则将样本分组
4. 在每个分组上计算评估指标
5. 输出统计结果
